# S01.3 — States, Responsive Rules & Interaction Foundation

## Reusable states

`StatePanel` defines loading, error, and empty presentations with distinct iconography, copy, borders, and optional recovery actions. State meaning never depends on color alone. The loading icon uses a low-key rotation that is suppressed by the existing reduced-motion token rule.

## Responsive shell

- Above 900px, the HQ uses the permanent 264px sidebar and full content region.
- At 900px and below, navigation becomes a contained horizontal rail above the content. Groups and planned insertion points remain available without creating page-level horizontal overflow.
- At 600px and below, page headers, cards, module insertion points, and application states become single-column. Table rows retain their comparison width inside a dedicated horizontal scroll container.
- Dialog and drawer widths are capped to the available viewport.

These are foundation rules, not device-specific product workflows.

## Command palette foundation

The global command palette opens from the header or with Command/Control + K. Escape closes it. It provides a search field, an available Lobby command, an instrument-drawer command, and visibly disabled future module commands. It does not execute business actions.

## Instrument drawer foundation

The global instrument drawer establishes a persistent right-side contextual surface. Its S01.3 content explicitly reports that no instrument or market source is connected. Future stages own selection and business data.

## Interaction and accessibility

- Native buttons, disabled states, labels, `aria-current`, modal roles, and headings preserve assistive semantics.
- Secondary navigation groups use native collapsed disclosures so future modules remain discoverable without dominating the permanent frame.
- Module insertion points use a quiet two-column list instead of a wall of nested cards.
- Keyboard focus uses the terracotta 3px focus ring.
- Escape closes both overlay foundations.
- Backdrop activation closes the relevant overlay.
- Reduced-motion preference suppresses non-essential animation.
- Overlay background blur and bounded surfaces preserve context without sacrificing text contrast.

## Palette refinement

The user-directed S01.3 refinement uses porcelain ivory (`#F7F6F1`), warm cream (`#EEECE3`), eucalyptus sage (`#A9B7A2`), deep sage (`#7E927C`), sea-glass blue (`#AFC7C8`), deep ink (`#2E3834`), soft slate (`#5F6B67`), muted apricot (`#E9A66B`), and terracotta (`#D98555`). Darker accessible companion tokens are used where text and focus contrast require them. This palette supersedes the earlier khaki/orange revision.
