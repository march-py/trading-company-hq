# S01.1 — Visual System

## Intent

The Trading Company visual system is dark-first, restrained, and information-dense. It prioritizes clear hierarchy, rapid comparison, explicit state communication, and predictable interaction feedback. The browser specimen in `src/App.tsx` is the reference implementation for this stage.

## Foundations

- **Surfaces:** canvas plus three stepped surfaces create depth with restrained borders and shadows. Accent color is reserved for focus, active state, and high-value emphasis.
- **Typography:** the operating interface uses the system UI stack. Financial data, metadata, and compact labels use the system monospaced stack.
- **Numerics:** market values use tabular figures and slashed zeroes. Positive, negative, and neutral directions have separate semantic tokens. Signs remain visible so color is never the only signal.
- **Spacing:** a 4px base scale supports compact controls and an 8px primary rhythm. Standard controls are 40px high.
- **Shape:** radii range from 6px for compact elements through 14px for panels. Pills are reserved for status labels.
- **Borders and shadows:** one-pixel borders establish structure. Shadows are low-opacity and only lift primary surfaces or focus.

## Status language

The canonical states are `NORMAL`, `ACTIVE`, `HEALTHY`, `ATTENTION`, `BLOCKED`, `DISABLED`, and `UNKNOWN`. Each combines a text label, icon, and semantic color. Product copy may become more specific while retaining the underlying tone.

## Icon direction

Icons use simple outline geometry, rounded caps and joins, a 24px view box, and a 1.6px stroke. Decorative icons are hidden from assistive technology; meaningful standalone icons require an accessible label.

## Hierarchy and density

Large display type is limited to presentation moments. Product headings are compact; metadata is uppercase and widely tracked. Tables preserve alignment with right-aligned numeric columns and tabular figures. Panels group related information without adding application navigation or layout behavior.

## Accessibility baseline

- Text and state colors are selected for legibility on their assigned dark surfaces.
- Keyboard focus uses a visible high-contrast ring.
- State is communicated with label, icon, and color.
- Motion is reduced when the operating system requests it.
- Native controls and semantic table roles preserve keyboard and assistive-technology behavior.

## Stage boundary

S01.1 establishes reusable tokens, status and icon primitives, and a visual specimen only. It does not define application navigation, sidebar behavior, shared layouts, command palette, instrument drawer, or responsive behavior. Those belong to later approved chunks.
